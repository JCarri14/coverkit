# Internationalization / Internacionalización

CoverKit has two separate language concepts:

1. **Interface locale**: `MediaCard locale="en" | "es"` controls component labels, accessible names and default count formatting. Default: `en`.
2. **Content language**: `MediaItem.language = {code: 'es', region: 'ES'}` describes the media item. It does not change with the UI locale.

```tsx
import { MediaCard, mediaCardLocales, formatMediaCount } from '@coverkit/react';

<MediaCard item={item} locale="es" />
<MediaCard item={item} locale="en" labels={{ new: 'Just added' }} />
formatMediaCount({value: 420,unit: 'pages'}, 'es'); // "420 págs."
mediaCardLocales.en.labels.ongoing; // "Ongoing"
```

Callers can override individual labels with `labels` and units with `countFormatter`. Unknown units are displayed as supplied. User-provided `MediaEntry.label`, `MediaCount.label`, titles and descriptions are never automatically translated by the component; the consumer owns the underlying content.

## Public website

The documentation and playground are available at:

- `/en/`, `/en/gallery/`, `/en/docs/`, `/en/components/media-card/`
- `/es/`, `/es/gallery/`, `/es/docs/`, `/es/components/media-card/`

Every page is prerendered with translated HTML, an appropriate `<html lang>`, canonical URL and reciprocal `hreflang` links. Switching language preserves the current section. The root path is an English redirect page with a manual Spanish alternative.

GitHub Pages deployment must set `COVERKIT_SITE_URL` and `VITE_BASE_PATH`, as described in `docs/PUBLISHING.md`. Static content should be confirmed by inspecting `apps/web/dist/en/docs/index.html` and `apps/web/dist/es/docs/index.html` after `pnpm check`.
